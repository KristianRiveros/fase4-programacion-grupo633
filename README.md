## Descripción

Este proyecto consiste en desarrollar un sistema en Python para la empresa Software FJ, que ofrece reservas de salas, alquiler de equipos y asesorías especializadas.

El programa permitirá gestionar clientes, servicios y reservas mediante programación orientada a objetos. Se implementarán validaciones y manejo de excepciones para controlar los errores y permitir que la ejecución continúe.

## Funcionalidades previstas

- Registro y validación de clientes.
- Creación de servicios de salas, equipos y asesorías.
- Cálculo de costos con variantes de impuestos y descuentos.
- Confirmación, cancelación y procesamiento de reservas.
- Manejo de excepciones personalizadas.
- Registro de errores y eventos relevantes en un archivo de logs.
- Simulación de al menos 10 operaciones válidas e inválidas.

## Organización de los datos

La información se gestionará mediante objetos y listas internas, sin utilizar bases de datos. Los archivos se emplearán únicamente para registrar eventos y errores.
